# sakral-bumma
Sistem Akuntansi Keuangan Relasi Alam &amp; Adat
Pengembangan aplikasi SAKRAL (Sistem Akuntansi Keuangan Relasi Alam dan Adat) agar dapat digunakan oleh berbagai BUMMA pada 7 Wilayah Adat di Papua dalam satu aplikasi. Pengembangan difokuskan pada penambahan Login BUMMA, Profil dan Identitas BUMMA, pemisahan data masing-masing BUMMA, serta penampilan identitas BUMMA pada Dashboard dan Laporan Keuangan. Seluruh desain, menu, logika akuntansi, PSAK 69, PSAK 16, TEV, Harmoni Kehidupan, dan fitur utama SAKRAL yang sudah tersedia tetap dipertahankan tanpa perubahan. Setiap BUMMA memiliki ruang data tersendiri sehingga transaksi, aset, jurnal, dan laporan tidak tercampur dengan BUMMA lainnya. Pada tahap ini sistem tetap menggunakan arsitektur aplikasi SAKRAL yang ada dengan penyimpanan lokal dan belum dikembangkan ke backend/database atau sistem administrator pusat.
